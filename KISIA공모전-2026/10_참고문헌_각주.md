# 참고문헌(APA)과 각주 처리 목록

> [!important] 요구사항 원문 (2026 신청서 작성 가이드라인)
> - 참고문헌은 **마지막 페이지**에 작성 (분량 15쪽에 **포함되지 않음**)
> - 저자명 · 제목명 · **발간·기고 일자** 표기
> - **특정 부분을 인용했을 경우 페이지도 함께 기재**
> - 표기법은 **APA 스타일** ([가이드](https://citation.sawoo.com/ref/guide/apa))

> [!success] 실존 검증 상태
> 아래 문헌은 **전부 이 프로젝트에서 원문 또는 원본 페이지를 직접 확인**했다. 허구 인용 0건.
> 학술논문 2편은 PDF 전문 확인, 법령 2건은 법제처 공개 API 원문, 정부 자료는 해당 기관 페이지 직접 확인.

## 1. 참고문헌 목록 (제출본에 그대로 옮길 것)

### 학술 문헌

>
> 이현우, 권익현. (2024). 정보보호 공시제도 의무화의 효과 분석과 제도 개선을 위한 제언. **한국산업보안연구, 14**(3), 133–166. https://doi.org/10.33388/kais.2024.14.3.133

⚠️ **페이지 주의**: KCI 서지정보에는 135–166으로 표기돼 있으나 **논문 헤더 기준은 133–166**이다. 원문을 따른다.

### 법령

> 정보보호산업의 진흥에 관한 법률, 법률 제19990호 (2024. 1. 9. 일부개정, 2024. 7. 10. 시행).
>
> 정보보호산업의 진흥에 관한 법률 시행령, 대통령령 제35801호 (2025. 10. 1. 타법개정, 2025. 10. 1. 시행).

*APA에는 한국 법령 인용에 관한 명시적 규정이 없다. 위 형식(법령명, 법률/대통령령 번호, 개정·시행일)은 국내 법학 논문의 통용 관례를 따른 것이며, 본문에서는 각주로 조문을 특정한다.*

### 팀원 조사 파트에 따라 추가될 수 있는 것

해외 사례(미국 SEC 사이버보안 공시 규정, EU NIS2 지침)를 III장·IV장에 넣기로 하면 여기에 추가한다. **1차 출처(SEC 최종규칙, EU 지침 원문)를 확인한 뒤에만 인용할 것** — 선행연구의 비교표를 재인용하면 카피킬러 유사도와 창의성 점수 모두 불리하다.

## 2. 각주 처리 목록

> [!danger] 각주가 카피킬러 대응의 핵심 수단이다
> 조문·정부문서를 **본문에 전재하면 유사도가 오른다.** 본문에는 요지만 쓰고 조문 특정은 각주로 내린다. → [[01_공모요강_체크리스트]] §6, [[03_집필설계_목차와논증]] 설계 원칙 4
> 각주 형식: 어구 **우측 상단**에 번호, 내용은 **각 면 하단** (한글 `Ctrl+N+N`)

집필 시 아래 항목에 각주를 단다. 표의 순서가 대략 본문 등장 순서다.

| 절 | 본문에는 이렇게 쓴다 (요지) | 각주에 넣을 것 |
|---|---|---|
| I | 정보보호 공시제도의 근거 규정 | 「정보보호산업의 진흥에 관한 법률」 제13조 제2항 |
| I | 의무 대상 기준(사업분야·매출액 3,000억·이용자 100만) | 같은 법 시행령 제8조 제1항 제1호~제3호 |
| I | 공공기관·소기업·금융회사 등 제외 규정 | 같은 법 시행령 제8조 제2항 |
| I | 정부의 확대 개정 추진 경과 | 과학기술정보통신부 공고 제2026-10호(2026. 1. 9.) 및 제2026-569호(2026. 5. 11.) |
| I | 소기업 2년 유예 부칙 신설 | 공고 제2026-569호 부칙 적용례. 소기업 기준은 「중소기업기본법 시행령」 제8조 제1항 및 별표 3(**평균매출액** 기준) |
| II-1 | 데이터 수집 방법·기간 | 수집 URL, 수집일(2026. 8. 6.), 요청 간격 1초, robots.txt 준수 여부 |
| II-1 | 분석표본에서 69건을 제외한 기준 | 총임직원 미기재 건. 제외 전후 결과에 차이 없음을 명시 |
| II-2 | 선행연구의 결과 | 이현우·권익현(2024), **pp. 151–152**(t-검정 결과) / 백승준·이홍주(2021), **p. 309**(초록) ← **인용 페이지 필수** |
| II-2 | 자기선택 편의 단서 | 자율공시 참여의 자발성으로 인한 표본 선택 편의 |
| II-3 | 임계값 도출 방법 | 격자탐색 범위(100~3,000명)와 선정 기준(상·하위 격차 최대) |
| II-4 | 인증·평가·점검이 이미 조건부 항목이라는 점 | 시행령 제8조 제3항 제3호 "해당하는 경우로 한정한다" |
| II-4 | 공시 항목의 작성기준이 고시 위임 사항이라는 점 | 시행령 제8조 제7항 |
| II-5 | 균형 패널 구성 방법 | 2022년 최초 공시 + 4개년 연속 공시 528개사 |
| III | 상장법인 수 | 한국거래소 KIND, 2026. 8. 6. 인출 |
| III | ISMS 의무대상 593개사 | 개인정보보호위원회·과학기술정보통신부(2026. 4. 10.), 2026년 2월 기준 |
| III | 신규 편입 추정의 한계 | 기업명 표기 차이로 인한 매칭 한계 → 범위로 제시한 이유 |
| IV | 검증·수정요청 권한이 이미 있다는 점 | 법 제13조 제4항(2023. 4. 18. 신설) |
| IV-3 | 제8조의2를 별도 조문으로 신설하는 이유 | 현행 제8조가 이미 제1항~제7항으로 구성돼 항 번호가 밀린다 |
| IV-3 | 규모별 차등 입법 선례 | 외감법 연결 내부회계관리제도 도입시기 차등(금융위원회, 2023. 12. 13.) |
| V | 이행 부담 추정의 전제 | 항목 수 기준 추정임을 명시 |

**합계 21개** — 6~15쪽 분량에서 페이지당 1.5~2개 수준으로 과하지 않다.

## 3. 인용 방식 — 해야 할 것과 하지 말 것

| ✗ 하지 말 것 | ○ 이렇게 쓸 것 |
|---|---|
| `제8조(정보보호 공시) ① 법 제13조제2항 본문에서 "대통령령으로 정하는 기준에 해당하는 자"란 …` (조문 전재) | `현행 시행령은 의무공시 대상을 사업 분야·매출액·이용자 수 세 가지 기준으로 정하고 있다.¹⁾`<br>`¹⁾ 「정보보호산업의 진흥에 관한 법률 시행령」 제8조 제1항.` |
| 정부 보도자료 문단을 그대로 옮기기 | 요지 한 문장 + 각주에 출처·발표일 |
| 선행연구 문장을 그대로 옮기기 | 결과 수치만 인용하고 **페이지 표기** |

> [!warning] 신구조문대비표는 예외지만 관리가 필요하다
> [표 4-1]은 성격상 조문 문구가 들어간다. **개정과 무관한 부분은 "(현행과 같음)"으로 생략**해 전재 분량을 줄이고, 표 아래에 출처를 명시한다. → [[08_IV3_조문시안_뼈대]] §3

## 4. 제출 전 점검

```
[ ] 본문의 모든 수치에 출처가 달려 있는가 → [[03_집필설계_목차와논증]] §3 논증 체크리스트와 대조
[ ] 참고문헌의 모든 항목이 본문에서 실제로 인용됐는가 (인용 안 한 문헌은 뺀다)
[ ] 본문에서 인용한 문헌이 참고문헌에 모두 있는가
[ ] 학술논문 인용에 페이지가 표기됐는가 (가이드라인 명시 요구)
[ ] 참고문헌이 마지막 페이지에 있는가
[ ] 각주 번호가 어구 우측 상단, 내용이 각 면 하단인가
[ ] URL·DOI가 실제로 열리는가 (제출 직전 재확인)
[ ] 법령 개정 여부 재확인 → python scripts\check_law_status.py
```
