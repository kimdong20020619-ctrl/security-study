# ✈️ 인천국제공항공사 이직 준비 (목표: 2030 가을 공채)

> **결론**: 진단·모의해킹으로 입사해 3년 경력을 쌓은 뒤 **2030년 가을 신입 공채(일반직 5급 · 기술 전산)**에 지원한다. 학력·경력 제한이 없어서 경력자도 신입 공채로 지원할 수 있다.
> **가장 먼저 넘을 관문은 TOEIC 800점**(지원 필수). 정보보안기사는 진단 직무와 공사 둘 다에 쓰여서 2027년에 먼저 딴다.
> **상위 노트**: [[직무결정-2026-10]] · [[포트폴리오-로드맵]]

## 1. 2025 공고 원문에서 확인한 사실

출처: [ALIO 2025 신입직원 채용 공고](https://www.alio.go.kr/mobile/information/informationRecruitDtl.do?seq=291137) — 공고문 이미지, 붙임1(채용분야별 자격증 우대사항), 붙임6(직무기술서)을 직접 열어 확인. 2026년 공고(일반직 42명, 접수 09-08~09-15)는 상세 첨부를 확인하지 못했다 → [링커리어 요약](https://linkareer.com/activity/347178)

| 항목 | 원문 내용 | 의미 |
|---|---|---|
| 채용 인원 | 일반직 42명 중 **전산 3명**, 통신전자 7명 | 서류 50배수 → 약 150명, 필기 3배수 → 약 9명 |
| **지원 필수 자격** | **TOEIC 800 이상** (또는 TOEFL-iBT 91 / TEPS 309 / JPT 800 / HSK 5급 210) · 학력·전공·연령·경력 제한 없음 | 어학이 1차 관문 |
| 근로조건 | **"일근 또는 교대근무"** | ⚠️ 전산이 어느 쪽인지 **미확인** — 현직자 후기로 확인 필요 |
| 서류 (100점) | 공인어학성적 + 우대사항 | TOEIC 점수가 높을수록 유리 |
| 전산 가점 5% | 정보처리기사, 전자계산기기사, 전자계산기조직응용기사, **정보보안기사**, 빅데이터분석기사, CISA·CISSP | **같은 구분 안에서는 가장 유리한 1개만** 인정 |
| 전산 가점 10% | 정보관리기술사, 컴퓨터시스템응용기술사 | 해당 없음 |
| 공통 가점 3% | 한국사능력검정 2급 이상 | 정보보안기사와 같은 구분 → 같이 있으면 5%만 |
| **가점 없음** | ADsP, SQLD, 네트워크관리사, 리눅스마스터, CPPG | 지금 가진·준비 중인 자격은 가점 0 |
| 필기 | NCS 50점 (의사소통·수리·문제해결·자원관리·정보·기술) + **전산 전공 50점** (전공과목 전반) · 각각 40% 미만 과락 | NCS와 전공을 따로 준비 |
| 면접 | 1차: 직무 PT · 상황 대처(Role Play) · 영어 / 2차: 종합면접 | 발표 연습 필요 |
| 전산 직무 내용 | 정보기술 전략, **보안엔지니어링(보안체계 운영관리·보안감사)**, IT 시스템 관리(NW·DB·보안 운영) · 필요 기술: Unix·Linux 서버, SQL, 개인정보보호 | 진단 경력·리눅스·네트워크·SQL이 **실무에서** 쓰임 |
| 지역인재 우대 | 비수도권 학교 출신만 | 해당 없음 |
| 어학 유효기간 | 인사혁신처 통합채용포털에 등록·확인된 성적은 **응시일부터 5년이 되는 해의 말일까지** 인정 | 한 번 따서 등록하면 몇 년 쓸 수 있음 (매년 공고에서 재확인) |

## 2. 준비 일정 (2030 가을 공채 기준)

| 시기 | 할 것 | 비고 |
|---|---|---|
| 2027 | **정보보안기사 취득** | 진단 취업에도 쓰임 → 공사 가점 5% 미리 확보 |
| 2027 하반기 ~ 2028-01 | 진단·모의해킹 입사 | [[직무결정-2026-10]] |
| 2028 ~ 2029 상반기 | 진단 실무 · (선택) 출퇴근 시간 LC 듣기 | 영어 감 유지만 |
| **2029 하반기 ~ 2030 상반기** | **TOEIC 집중 → 800점 확보 → 통합채용포털 등록** | 공채 1년 전. 처음부터 800까지는 수백 시간짜리로 잡는다 |
| 2030 상반기 | **NCS + 전산 전공 필기** (정보처리기사 범위가 기준) | 직무 PT·영어 면접 연습도 |
| **2030 가을 (보통 9~10월)** | 공채 지원 → 필기 → 면접 | 어학·자격증은 접수 마감일까지 공식 발표된 것만 인정 |
| 떨어지면 | 다음 해 공채 재도전 | 포털에 등록한 TOEIC 점수가 유효한지 확인 |

> TOEIC 기간 근거: 처음부터 800점까지 걸리는 기간은 믿을 만한 통계를 찾지 못했다. 오래된 연구(Saegusa, 1985)는 350→550점에 약 450시간이 걸린다고 추정했다 ([재인용 논문](https://miyazaki-mu.repo.nii.ac.jp/record/1107/files/23%281%29_009_Bingham.pdf), [구형 데이터, 1985년 기준]). "2~3개월에 800점" 같은 후기는 성공 사례라 일반화하지 않는다.

## 3. 검토했지만 택하지 않은 안 — 신입 직행 (2027 가을 공채)

- 2026-10부터 TOEIC을 시작해 2027-06까지 800점을 따고, 여름방학에 NCS·전공을 준비해 2027 가을 공채에 진단과 동시에 지원하는 안.
- **택하지 않은 이유**: 방학 두 번을 공사 준비에 써야 해서 진단 포트폴리오(웹 보안·TryHackMe)가 얇아지고, 전산 3명 경쟁에서 떨어질 가능성이 높다.

## 4. 확인할 것

- [ ] 전산직이 실제로 교대 근무인지 (현직자 후기·잡플래닛·블라인드)
- [ ] 다음 공채 공고(매년 9~10월)의 첨부파일로 위 표 갱신 — 가점표·필기 과목·어학 기준이 바뀌는지
- [ ] 경력직 정보보안 채용이 따로 열리는지 (2026-10 검색 시 없음)
