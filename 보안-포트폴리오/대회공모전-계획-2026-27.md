### 2026 동남 버그바운티 — 공고 확인 (2026-10-05)

| 항목 | 내용 |
|---|---|
| 발주·운영 | 재단법인 부산정보산업진흥원 발주(조달청 부산지방조달청 공고) · 운영 **파인더갭**(버그바운티 플랫폼) |
| 참가 대상 | 전국 누구나 (**만 19세 이상**) — 대학생 가능 |
| 기간 | 접수 2026-09-21 ~ **11-13**, 대회는 접수 기간 동안 온라인으로 진행 |
| 상금 | 총 1,000만 원 + 기관장상 3종, 상장 |
| 사전 OT | 9-21(월) 18:00~21:00 온라인 웨비나 — **이미 지남. 다시보기 여부는 미확인** (취약한 소스코드·공격 재현·리포트 작성까지 다룸) |
| 신청 | 파인더갭 홈페이지 (findthegap.co.kr) |
| 미확인 | 대상 서비스·범위, 금지 행위, 결과 발표일 — 홈페이지 첫 화면에는 대회 상세가 없음 |

> ⚠️ **범위 밖은 절대 건드리지 않는다.** 버그바운티는 공개된 대상과 규칙 안에서만 허용된다. 가입 후 프로그램 페이지에서 대상·금지 행위를 먼저 읽고, 범위가 불분명하면 문의(contact@findthegap.com)한 뒤 시작한다.
> 현재 실력(SEC1 진행 중, 웹 보안 전)으로 수상은 기대하지 않는다. 목표는 **실제 리포트 1건 제출 시도 + 경험**이다.

### 진행 순서 (2026-10-05 확정 — 위 3개로 압축)

**순서: ① 생성형 AI 위험성 찾기 → ② 데이콘 항만 → ③ 동남 버그바운티.** 마감 순서와 같고, 준비가 덜 된 버그바운티를 마지막에 몰아서 한다.

| 기간 | 주력 | 같이 할 것 (가볍게) |
|---|---|---|
| **10-05 ~ 10-11** | **① 생성형 AI 위험성 찾기** — 위험한 답변 사례를 모아 **10-11까지 제출** (마감 하루 전) | 데이콘 항만 **참가 신청** · **파인더갭 가입 → 버그바운티 범위·규칙만 읽기** (테스트는 아직 안 함) |
| **10-12 ~ 10-18** | **② 항만 1주 차** — 데이터 공개(10-12). 데이터 구조·평가지표 파악, 가장 단순한 기준 모델로 **첫 제출** | GPU 필요 여부 판단 → 필수면 중단하고 ③으로 |
| **10-19 ~ 10-26** | **② 항만 2주 차** — 점수 개선. 팀을 꾸린다면 **10-26 팀 병합 마감** 전에 결정 | 주말에 버그바운티 대상 정찰만 (범위 안에서) |
| **10-27 ~ 11-01** | **② 항만 마지막 주** — **11-01 리더보드 마감**. 코드 검증 대비로 코드를 정리하고 직접 설명할 수 있게 | — |
| **11-02 ~ 11-13** | **③ 동남 버그바운티 집중 2주** — 범위 안에서 취약점 찾기 → **리포트 1건 제출** | 항만 본선 진출 시 11-05 코드 검증, 11-10 발표평가 |

- **이유**: ①은 마감 7일 전, 1~2시간짜리. ②는 10-12~11-01 고정 일정, 주 5시간 상한. ③은 기간이 가장 길지만(~11-13) 웹 보안 실력이 필요해서 앞 기간엔 범위 확인·정찰만 한다.
- **비용**: 이 기간 TryHackMe SEC1 재개(10월 중순)가 밀린다 → 버그바운티 기간에 웹 보안 룸을 같이 보며 일부 보완.
- **바뀌는 조건**: 10-12에 공개된 항만 데이터가 GPU 필수이거나 감이 안 오면, 첫 제출만 하고 바로 ③으로 넘어간다.
