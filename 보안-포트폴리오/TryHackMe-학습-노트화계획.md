## 학습 축 (실측 확인)

**방향 (2026-10-05 확정): 취약점 진단·모의해킹 신입 → 2030 인천공항공사 이직 → 장기 CERT·위협 분석.** 근거: [[직무결정-2026-10]]. TryHackMe 갈래를 이 방향에 맞춰 다시 선택:

| 갈래 | 결정 | 이유 |
|------|------|------|
| **침투 테스터 (Jr Penetration Tester)** | ⭐ **메인 경로** (7월의 '스킵'을 뒤집음) | 진단·모의해킹 직결. 2026년 개편, 웹·네트워크·권한상승·AD 기초, 약 70~90시간 ([TryHackMe](https://tryhackme.com/r/path/outline/jrpenetrationtester)) · 자격 **PT1**(48시간 실기, 여력 시) |
| 보안 분석가(SOC) | SOC Level 1은 **취업 후로** | CERT·위협 분석으로 넓힐 때 |
| 보안 엔지니어(Security Engineer) | 후순위 | AD 기초는 Jr Penetration Tester에서 다룸 |
| AI 보안 | 차별화(여력 시 AI1) | "AI 관심+역량 보안 신입" 어필 |

**추천 순서**: SEC1 완주(약 46%, 10월 중순 재개) → **웹보안 기초**(SQLi·XSS·Burp·OWASP Top 10) → **Jr Penetration Tester** → (여력 시) PT1 → 취업 후 SOC1 → AI Security.
> 코딩이 약하므로 실습마다 **요청·응답과 코드 흐름을 읽고 설명하는 것**을 노트에 남긴다. 직접 짜는 스크립트는 최소.

> ☁️ **클라우드 제외로 재정정 (2026-09-24)**: 2026-07-14의 "AWS 방어 1개 포함" 방침을 철회. 진로는 **클라우드 보안만 제외한 보안 전반**. AWS 방어 모듈은 건너뛰고 [[AWS방어-입문계획]]은 보류 보관.
> 드림핵은 공격 중심이라 **선택 보조**(과투자 금지).

## 18개월 학습 일정

> **페이스 전제 (냉정·현실)**: 알바+학교+기타 병행 = 지속 가능한 보안 자기학습 **평균 주 3~4시간**(시험기간엔 0에 가까움). 방학 인텐시브는 단기만 유효.

| 시기 | TryHackMe (현실 목표) | 걸림돌 |
|------|------|------|
| **2026 Q3 (7~9월)** | SEC1 37% → **약 46%** (8월 완주 미달) | 개강 후 캡스톤으로 정지 |
| **2026 Q4 (10~12월)** | **SEC1 재개**(10월 중순~, 주 2~3h) | 10-11까지 공모전·데이콘 마감 / 캡스톤 / 기말고사 |
| **2027 Q1 (1~3월)** | 겨울방학: **SEC1 완주 → 웹보안 기초 → Jr Penetration Tester 착수** | 정보보안기사 필기 공부 병행 |
| **2027 Q2 (4~6월)** | **Jr Penetration Tester 진행** (웹·권한상승) | 전공심화 + 정보보안기사 실기 |
| **2027 Q3 (7~9월)** | Jr Penetration Tester 마무리 (AD 기초) · (여력 시) PT1 | **진단 공채 지원** |
| **2027 Q4 (10~12월)** | 복습·부족분 보완 → 취업 마무리 | 면접 (늦어도 2028-01 입사) |

> (2026-10-05) 아래 "냉정한 결론"은 7월 관제·SE 기준으로 쓴 것이다. 지금 기준은 위 표다: **2027 안 현실 목표 = SEC1 + 웹보안 + Jr Penetration Tester.**

### 냉정한 결론
- **2027 안 현실 목표 = SEC1 + SOC1 + 보안 엔지니어 경로 일부(AD·DevSecOps).** 전 과정 완주·SAL2·SOC2는 무리 → 취업 후로.
- 2027엔 **정보보안기사(최우선) + 홈랩 프로젝트 + 전공심화 + 취업준비**가 시간 경쟁. 주 3~4h로는 전부 불가 → 우선순위 필수.
- **보안 신입엔 SOC1 + 보안엔지니어 기초(AD 등) + 홈랩 SOC + AI 차별화**면 지원 경쟁력.
- ⚠️ (2026-09-24) SOC1 착수가 겨울방학으로 밀려 2027 Q2의 Security Engineer 시작도 늦어질 수 있다. 2027 Q1 말에 SOC1 진도를 보고 다시 판단.
- 프로젝트도 8개 다 깊게 X → 홈랩 SOC + 1~2개만 실데이터로 깊게.

### ✅ 확정 형식 — "복습용 노트" (2026-07-14 확정, SEC1부터 적용)

한 번 훑고 와도 이 노트만 읽으면 바로 이해되게. [[01_start-your-cyber-security-journey]]가 표준 예시.

| 순서 | 섹션 | 내용 |
|:--:|------|------|

| 2 | **🔎 쉽게 말하면** | 룸/개념마다 일상 비유 (예: 공격=도둑, 방어=경비원) |
| 3 | **🖐️ 내가 실제로 한 것 (단계별)** | 친 명령이 **뭘 한 건지**까지 설명 (예: dirb=숨은 페이지 탐색) |
| 4 | **💡 그래서 핵심** | 룸별 핵심 takeaway 2~3개 |
